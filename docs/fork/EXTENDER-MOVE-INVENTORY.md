# Built-in extender reads of families scheduled to move

Generated by `python3 scripts/fork/extender_move_inventory.py --out docs/fork/EXTENDER-MOVE-INVENTORY.md`. Do not edit by hand.

The field offsets and the command names come from the built-in crates' command source (issue #916, ADR-0014). A family that has moved holds poison in these fields: a command must reach the object through its virtual methods or the family's typed functions at their exe addresses, not by reading or writing them. The tracked fields are the `FIELDS` table in the generator; add a token there when a family's move is planned. Fields marked `moved` fail the guard when a command accesses one directly; none is marked yet.
